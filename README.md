## 현재 판정

| 항목 | 확보한 근거 | 아직 주장할 수 없는 것 |
|---|---|---|
| 초단기 +1~4h | 배포 번들, Shadow 수집·평가 체계 | 장기 운영 안정성 통과 |
| 단기 +24h | 4지역 후보, 별도 Shadow 조립기 | 4지역 상시 예측 성공 |
| 단기 +48h | 부안·김제·영광 후보 | 광주 후보 완성, 충분한 계절 검증 |
| 월간 | 광주·영광 동일표본 기준선 비교 | GB-Huber 공식 승격 |
| 수집 | KIM NC 유효값 수신 사례, 장애 대응 | 전체 710일 NC 완성·지속 정상 |

`+24h/+48h`는 이 프로젝트의 **풀링된 익일/모레 예측 구간 라벨**입니다. 정확히 24시간/48시간 뒤 한 점과 동일하지 않습니다. 평가 시 실제 lead와 발행시각을 함께 확인해야 합니다.

## 저장소 구조

```text
code/       원래 단계별 폴더를 유지한 연구 코드 (legacy source)
docs/       의사결정·지역별 요약·출처·산출물 목록
figures/    기존 실험 그림 9개 + 저장된 OOF로 다시 생성한 월간 그림 4개
results/    월간 OOF, 동일표본 재계산 지표, 근거 manifest
scripts/    공개된 OOF로 그래프·지표 재생성
```

## 재현 가능한 범위

Python과 `pandas numpy matplotlib`를 설치한 환경에서:

```bash
python scripts/render_monthly_evidence.py
```

저장된 월별 out-of-fold 예측을 읽어 MAE·RMSE·WAPE와 4개 그림을 다시 생성합니다. **모델 재학습은 하지 않습니다.** Windows는 맑은 고딕을 사용하며, 다른 운영체제에서는 스크립트의 폰트를 설치된 한글 폰트로 바꾸십시오.

`code/`는 원본 경로와 실험 버전을 보존합니다. 일부는 개인 PC 절대경로·비공개 DB·비공개 모듈에 의존하므로 그대로 전체 실행할 수 없습니다. 운영 스케줄러 등록·수집 스크립트를 무작정 실행하지 마십시오. 전 코드의 이식성 검증이나 패키징 완료를 주장하지 않습니다.

## 공개 범위와 안전

코드 339개를 목록화했고, 인증 관련 문자열을 포함한 41개는 보수적으로 공개에서 제외했습니다. 공개 코드 298개는 비밀키가 포함된 파일을 마스킹하여 실행가능한 척 만든 것이 아니라, 해당 파일 자체를 제외한 원본 복사본입니다. 원시 발전소 DB·Excel·NC·API 키·모델 바이너리·운영 로그는 공개하지 않습니다. 평가용 월별 OOF 및 요약 지표만 포함합니다.

새 라이선스는 임의로 부여하지 않았습니다. 기관 데이터와 코드의 재배포·이용 권한은 소유자에게 확인하십시오.

## 근거 원칙

국내 논문의 방법론 배경, 프로젝트 자체 실험, 운영 정책을 분리합니다. 논문에 없는 10분 보간 상한·VIF 임계값·GB-Huber 선택을 국내 학술 정답으로 표현하지 않습니다. 그림은 실험 산출물을 사용하며, 표현 목적의 가상 그래프를 실측 결과로 제시하지 않습니다.
