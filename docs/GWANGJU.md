# 광주 — 2026-09-10 근거 정리

## 현재 결론

공식 기준 보존, 새로운 단기·월간은 후보입니다. 오프라인 예측 가능성과 최신 라이브 성공은 구분합니다. 기존 모델이 요구한 DSWRFLX·장비온도 등은 최신 입력에서 재현이 어려워 후보 특성 스키마를 다시 구성했습니다. 과거 번들을 삭제하거나 수치만 바꿔 공식으로 표시하지 않습니다.

## 자료·품질

기존 구간2024-08-25~2026-08-04와 신규2026-08-26~09-09 사이에는 실제 공백505시간이 있습니다. 연속1시간 reindex로 NaN 행을 유지하고 segment별 lag/rolling을 사용합니다. 학습 가능한 행이 충분하더라도 신규 구간 NWP 결측으로 라이브 평가가 안 될 수 있습니다.

등록240kW·인버터합계219kW·모델기준219kW는 서로 다른 정의입니다. 장비 정보 확보는 정격 검증 완료와 동일하지 않습니다. 인버터5 장기 무응답은 0발전으로 채우지 않습니다.

## 전처리 선택 근거

![광주 10분 공백 비교](../figures/evidence_04.png)

## 단기 후보

09.10 파일 감사의 +24h는 LightGBM26특성, 학습122,205·시험7,153행, MAE11.492/RMSE17.750kW입니다. 학습행수는 고유시간 개수가 아닐 수 있습니다. 이전 +1h 후보의6,906행 기록과 서로 다른 버전/대상을 혼합하지 않습니다. +24h는 익일 풀링 구간이며 고정24시간 한 점이 아닙니다. 광주 +48h는 이번7개 감사 대상에 없습니다.
