# 09.10 — 작업 기록·검증·디자인 피드백

## 오늘의 한줄 요약

API 장애 대응과 별개로 단기 후보7개를 파일 감사하고 월간 기준선을 재검증했다. 실제 분석 결과를 Notion·GitHub용으로 정리했으며, 모델 승격과 라이브 정상화는 보류한다.

## 데이터 수집·운영

- KMA 연결 장애 및 ASOS08:00·GRID00시대 정체가 보고·확인된 기록. 모든 기상청 사이트가 동일하게 중단됐다고 확대 해석하지 않음.
- 시간당 백필이 지역별 장시간 대기로 다음 실행과 겹치는 문제에 대해 사전 연결확인·짧은 재시도·실행시간 제한 대응. 대응 완료와 API 복구는 별개.
- ASOS/GRID 수집도 동일한 장시간 대기를 제한. 실제 신규 DB행은 복구 후 재확인해야 함.
- 로컬 collection_status 페이지 연결 중단 후 서버를 다시 띄워 HTTP200 확인한 기록. 상시 서비스 감독·자동 재부팅 복구까지 구축됐다는 뜻은 아님.
- 대시보드 보류/조건부 생성률은 보조 표시. 원시 생성률을 보존하고 장애 제외기간·게이트 기대 슬롯을 별도 검증해야 함.

## 디자인 검토

저장된 `태양광 대시보드 리디자인.dc.html`의 종합현황·예측결과·인버터·발전성능·모델검증·수집6개 화면을 실제 브라우저에서 확인했다. 공유 URL은 로그인으로 전환돼 최신 공유본과 동일 여부는 확인하지 못했다. 피그마 파일은 생성됐으나 화면 가져오기는 권한 심사에서 차단됐다. 디자인 검토와 수정 요구사항은 진행 가능하며, 실제 피그마 편집 완료로 보고하지 않는다.

주요 수정: 모델표 가로스크롤/좁은 열, 수집표 하단 겹침, 잘못된 NWP 의존성, 용량240.6/241 표기, 불완결일 PR57% 강조, 인버터 용량 무시한 평균편차 경고. 세부는 [디자인 피드백](DESIGN_REVIEW.md).
