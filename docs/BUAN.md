# 부안 — 2026-09-10 근거 정리

## 자료와 운영 제약

부안은 발전이력 표본기간이 김제·영광보다 짧습니다. 과거 구축 기록의 시간집계5,652행·결합 유효4,740행과710일 기상자료를 같은 규모로 쓰면 안 됩니다. 기상이 오래 있어도 발전량 타깃이 없으면 학습 표본이 늘지 않습니다. 가을 표본 부족에 따른 중장기 미구축 정책은 유지합니다.

ASOS 실측 일사는 지점별 가용성이 다르므로 부안의 해당 관측소에서 직접 확보됐다고 단정하지 않습니다. 인근관측·예보일사·실측일사는 별도 출처입니다. 라이브 수집 공백률과 과거 Excel의 결측률도 분리합니다.

## 4계절 기준선 상태

부안은 라이브 발전량 브릿지로 초단기·D+1 검증을 갱신했지만, 동일한 폴드 내부 climatology 기준선의 4계절 표는 아직 산출하지 않았습니다. 가을 실측이 충분히 쌓이기 전에는 계절 성능을 확정하지 않고 `판정보류`로 유지합니다.
